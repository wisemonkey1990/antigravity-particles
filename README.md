# Antigravity 粒子光环复刻

复刻 [antigravity.google](https://antigravity.google) 页面上跟随鼠标的粒子光环效果。单个 `index.html`，无依赖，直接用浏览器打开即可。

## 原理

原版是 Three.js + WebGL 的 GPGPU 粒子系统（`MainParticlesComponent`），本仓库把同一套数学搬到 CPU + Canvas2D，逻辑一一对应，方便阅读。

1. **撒点**：泊松圆盘采样均匀撒点，作为每个粒子的原位（这里用抖动网格近似）。
2. **光环跟随鼠标**：每帧 `ring += (target - ring) * 0.02` 缓动；鼠标离开时降为 0.01 并叠加噪声游走。环半径随 `sin/cos(time)` 呼吸。
3. **模拟**：原版把每个粒子的位置和大小存在 256×256 浮点纹理里 ping-pong。对每个粒子用 `smoothstep` 算出“环带权重”，据此放大粒子、沿环心方向推开，并叠加多层 simplex 噪声和正弦波漂动。
4. **渲染**：每个粒子是点精灵，用圆角矩形 SDF 画成小胶囊，按到环心的角度旋转，呈放射状。
5. **配色**：低频噪声在蓝 `#2c64ed`、红 `#f84242`、黄 `#ffcf03` 之间插值。

参数（环宽 0.011 / 0.107、推力 0.53、密度 230、粒子缩放 0.59）取自原页面 DOM 上的 `data-*` 属性。
